# Rashed Alabidi — Personal Portfolio

A responsive bilingual (Arabic / English) portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, typography, animations
- `script.js` — language switcher, mobile menu, project filters, reveal effects

## Run on Android
1. Download and extract `rashed_portfolio.zip`.
2. Open `index.html` using your preferred code editor or browser.
3. To edit the site, open the files in a text/code editor. Keep all three files in the same folder.

## Before publishing — replace these placeholders
1. In `index.html`, replace `YOUR_EMAIL@example.com` in both the email link and visible text.
2. Add your real university name and study dates where the page says `Add university name · Add dates`.
3. Add a PDF named `cv.pdf` and a download link if you want a CV download button. The current site intentionally does not claim a CV file exists.
4. Add real links to project demos, GitHub, LinkedIn, and social accounts when available.
5. Review the project descriptions and skills to ensure they reflect your current status accurately.

## Publish
You can upload the extracted files to GitHub Pages or another static hosting service. No build tools or server are required.
